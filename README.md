# Product-Software

פלטפורמת השוואת ספקים לעסקי מזון: הלקוח בונה סל רכש חודשי, והמערכת משווה אותו בין ספקים לפי המחיר שמגיע לו בפועל (מדרגות לפי היקף הרכש אצל כל ספק), דמי משלוח, מינימום הזמנה, דירוג ואמינות. הפלטפורמה היא כלי השוואה בלבד: ההזמנה עצמה נעשית ישירות מול הספק. כל המחירים ללא מע״מ.

## מה יש כרגע (שלב 0)

- אפליקציית Next.js 15 + TypeScript + Tailwind, בעברית ומימין לשמאל.
- מודל נתונים מלא ב-Prisma/PostgreSQL ([prisma/schema.prisma](prisma/schema.prisma)). סכומים נשמרים באגורות.
- הרשמה והתחברות לשלושה תפקידים: לקוח, ספק ואדמין. במסך הכניסה בוחרים "מסעדה" או "ספק". ספק חדש ממתין לאישור.
- אזור ספק: רשימת המוצרים (רשימה או קוביות), חיפוש, סינון לפי סוג מוצר בסרגל הצד, הוספה, עריכה, מחיקה, פרטים והיסטוריית מחירים, ופרטי פרופיל. שינוי מחיר של יותר מ-30% ממתין לאישור אדמין.
- מנוע אופטימיזציה ([src/lib/engine](src/lib/engine)) שמחזיר שלוש אפשרויות: העלות הנמוכה ביותר, ספק יחיד ושילוב מומלץ לפי העדפת הלקוח, עם הסבר.
- נתוני דמו: 6 אזורים, 18 קטגוריות, 21 מוצרים קנוניים, 4 ספקים מומצאים ולקוח עם הסל מהאפיון.

## הרצה מקומית

### הדרך הקלה: Docker (בלי להתקין Node או מסד נתונים)

1. מתקינים [Docker Desktop](https://www.docker.com/products/docker-desktop/) ופותחים אותו.
2. מורידים את הקוד: ב-GitHub, בענף `mvp-build`, לוחצים Code ← Download ZIP ומחלצים (או `git clone -b mvp-build https://github.com/matanshemtov112/Product-Software.git`).
3. פותחים טרמינל בתיקייה (ב-Windows: PowerShell) ומריצים:

```bash
docker compose up
```

4. בהרצה הראשונה זה לוקח כמה דקות. כשמופיע `Ready` נכנסים ל-http://localhost:3000.
5. לעצירה: Ctrl+C. בפעם הבאה שוב `docker compose up`, והנתונים נשמרים.

- להתחלה מחדש עם נתוני הדמו: `docker compose down -v` ואז שוב `docker compose up`.
- לא חובה: כדי להפעיל חיפוש בצילום וקריאת חשבוניות, יוצרים בתיקייה קובץ `.env` עם השורה `ANTHROPIC_API_KEY="..."`.

### בלי Docker

דרוש Node.js 22 ו-PostgreSQL 16.

```bash
cp .env.example .env        # ולעדכן את DATABASE_URL ואת SESSION_SECRET
npm install
npm run db:migrate          # יוצר את הטבלאות
npm run db:seed             # נתוני דמו (מוחק את כל הנתונים הקיימים!)
npm run dev                 # http://localhost:3000
```

חשבונות דמו (סיסמה `demo1234`): `customer@demo.local`, `supplier1@demo.local` עד `supplier5@demo.local`, `admin@demo.local`.

## חיפוש מוצר בצילום

הלקוח מצלם מוצר, והמערכת שולחת את התמונה ל-Claude (מודל `claude-opus-5-5`) יחד עם רשימת המוצרים בקטלוג. Claude מחזיר אילו מוצרים מהקטלוג מופיעים בתמונה ואילו דומים להם, והמערכת מציגה את הספקים באזור של הלקוח שמוכרים אותם ([src/lib/photo-search](src/lib/photo-search)).

- כדי להפעיל: להגדיר `ANTHROPIC_API_KEY` בסביבת השרת. בלי מפתח המסך מציג שהחיפוש לא הופעל, ושאר המערכת עובדת כרגיל.
- כל חיפוש הוא קריאה בתשלום ל-API של Claude.
- אם המודל מסרב לבקשה מסיבות בטיחות, ה-API מריץ אותה אוטומטית על מודל חלופי (`fallbacks: "default"`).
- לבדיקות בלי מפתח (לא בייצור): `PHOTO_SEARCH_FAKE_RESULT='{"description":"...","exact":["פטריות שמפיניון"],"similar":[]}'`.

## העלאת חשבונית

הלקוח מצלם או מעלה חשבונית (תמונות או PDF, עד 5 עמודים). Claude קורא ממנה את הספק, השורות, הכמויות והמחירים (ללא מע״מ), ומתאים כל שורה למוצר בקטלוג לפי השם, הקטגוריה והשמות הנרדפים. במסך הבדיקה הלקוח מתקן שורות שסומנו בצהוב, ואז נוצר סל עם הספק הנוכחי והמחירים של היום, ישר להשוואה. הקובץ עצמו לא נשמר, רק השורות שנקראו (טבלת `Invoice`).

- משתמש באותו `ANTHROPIC_API_KEY` של החיפוש בצילום.
- לבדיקות בלי מפתח (לא בייצור): `INVOICE_FAKE_RESULT='{"supplierName":"...","invoiceDate":"2026-10-20","pricesIncludeVat":false,"lines":[{"text":"קנולה פח 18 ל׳","product":"שמן קנולה","quantity":36,"unitPrice":9.8,"confidence":"high","note":""}]}'`.

## איך המנוע עובד

1. מסננים ספקים מאושרים שמספקים לאזור הלקוח ומוכרים לפחות פריט אחד מהסל.
2. אם יש יותר מ-20 כאלה, משאירים את המבטיחים ביותר (ספק שהוא היחיד שמוכר פריט נשאר תמיד).
3. בודקים כל צירוף של עד 4 ספקים. בכל צירוף כל פריט הולך לספק הזול ביותר, הכמות מעוגלת לגודל האריזה, והמדרגה נקבעת לפי ההיקף החודשי אצל אותו ספק.
4. ספק שלא מגיע למינימום הזמנה לאספקה מקבל את הפריט שהעברתו אליו הכי זולה; אם אי אפשר, הצירוף נפסל.
5. דמי משלוח לכל אספקה, אלא אם ההזמנה מעל סף המשלוח החינם.
6. ציון משוקלל: מחיר, דירוג ואמינות לפי העדפת הלקוח, פחות קנס קטן על כל ספק נוסף. "מחיר קודם" תמיד בוחר את הזול ביותר.
